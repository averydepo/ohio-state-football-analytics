# Ohio State Football Analytics

An interactive Power BI analytics project exploring Ohio State football performance from 2015–2026 using data from the CollegeFootballData API.

## Project Overview

This project uses historical college football data to explore Ohio State's team performance, player statistics, and trends across multiple seasons.

The goal was to transform publicly available football data into an interactive dashboard that makes it easier to explore team statistics, evaluate performance, and identify historical trends.

## Tools & Technologies

- **Power BI Desktop:** Data modeling, dashboard development, and visualization
- **Power Query:** API data retrieval and transformation
- **DAX:** Measures and calculations
- **CollegeFootballData API:** Source of football statistics and historical data

## Data Source

Data was retrieved from the [CollegeFootballData API](https://collegefootballdata.com/), which provides publicly available college football statistics, game results, team information, and player data.

Seasons covered: 2015–2026.

## Dashboard Features

- Interactive team performance analysis
- Player vs player statistics and performance
- Game and team statistical season trends
- Next game preview and predictions
- Interactive filters and visualizations
