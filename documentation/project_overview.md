# Project Overview 

## Project Description
The Ohio State Football Analytics project is an interactive Power BI dashboard designed to explore Ohio State football performance across the 2015-2026 seasons. This project brings together historical football statistics and transforms them into interactive visualizations. 

## Objectives
The primary objectives of this project were to:
- Retrieve historical college football data using the CollegeFootballData API.
- Transform and organize raw API data for analysis in Power BI.
- Develop an interactive dashboard to explore Ohio State football statistics.
- Analyze team and player performance across multiple seasons.
- Present historical trends and statistical comparisons through data visualizations.
  
## Tools and Data Sources 
- Power BI Desktop: Dashboard development, data modeling, and visualization.
- Power Query: Data retrieval and transformation.
- CollegeFootballData API: Source of historical college football data.

## Project Purpose 
This project demonstrates the use of API-based data integration, data transformation, and interactive data visualization to turn publicly available sports statistics into an analytical dashboard. It was developed as an independent project to strengthen practical data analytics and business intelligence skills.
